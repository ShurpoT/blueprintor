A module and its test in the folder where you run the blueprint.

## Blueprint

```js
{
  title: "Python module with a test",
  variables: [{ key: "name", prompt: "Module name" }],
  structure: {
    files: [
      {
        name: "{name.snake}.py",
        content: [
          "class {name.pascal}:",
          "    def run(self) -> str:",
          '        return "{name.raw}"',
        ],
      },
      {
        name: "test_{name.snake}.py",
        content: [
          "from {name.snake} import {name.pascal}",
          "",
          "",
          "def test_run() -> None:",
          '    assert {name.pascal}().run() == "{name.raw}"',
        ],
      },
    ],
  },
}
```

### Result

With `user service`:

<FileTree>

- user_service.py
- test_user_service.py

</FileTree>

<Tabs>
<TabItem label="user_service.py">

```python
class UserService:
    def run(self) -> str:
        return "user service"
```

</TabItem>
<TabItem label="test_user_service.py">

```python
from user_service import UserService


def test_run() -> None:
    assert UserService().run() == "user service"
```

</TabItem>
</Tabs>

The file names use `snake`, the class uses `pascal`. Braces in Python code, for example in f-strings such as `{value}`, are not touched.
