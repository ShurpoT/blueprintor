## Blueprint

```js
{
  title: "SQL: create and drop database",
  variables: [{ key: "db", prompt: "Database name" }],
  structure: {
    files: [
      {
        name: "create_{db.snake}.sql",
        content: [
          "-- Create the database: {db.raw}",
          "CREATE DATABASE IF NOT EXISTS {db.snake};",
          "USE {db.snake};",
        ],
      },
      {
        name: "drop_{db.snake}.sql",
        content: [
          "-- Delete the database: {db.raw}",
          "DROP DATABASE IF EXISTS {db.snake};",
        ],
      },
    ],
  },
}
```
