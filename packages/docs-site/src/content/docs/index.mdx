## Why Blueprintor

<CardGrid>

<Card title="Any structure" icon="document">

Nested folders, several files, shared texts. A React component with styles and a test, a Python module, a Go package, task notes: whatever you create again and again.

</Card>

<Card title="Smart placeholders" icon="pencil">

One input becomes `{name.pascal}`, `{name.camel}`, `{name.kebab}`, `{name.snake}` or `{name.raw}` in file names, folder names and content.

</Card>

<Card title="Global and local" icon="setting">

Keep personal blueprints in VS Code settings and project blueprints in `blueprintor.config.js`. On the same title, the local one wins.

</Card>

<Card title="Safe by default" icon="approve-check">

Everything is checked before writing, so a mistake in a config never leaves a half-created result. Existing files are never overwritten without asking.

</Card>

</CardGrid>

## How it looks

Describe a blueprint once:

```js title="blueprintor.config.js"
module.exports = {
    blueprints: [
        {
            title: "Idea",
            variables: [{ key: "name", prompt: "Idea name" }],
            snippets: {
                idea: `
# {name.pascal}

Notes go here.
`,
            },
            structure: {
                files: [{ name: "{name.kebab}.md", snippet: "idea" }],
            },
        },
    ],
};
```

Right-click a folder, choose **Run Blueprintor...**, pick the blueprint and type `my idea`:

<FileTree>

- ideas
    - **my-idea.md**

</FileTree>
