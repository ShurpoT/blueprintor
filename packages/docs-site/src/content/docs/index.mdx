## Why Blueprintor

<CardGrid>

<Card title="Any structure" icon="document">

Generate complex boilerplates instantly. Build templates with nested folders, multiple files, and predefined text.

Perfect for anything you create again and again:

<FileTree >

- src/
  - components/
    - Button/
      - Button.tsx
      - Button.test.tsx
      - styles/
        - button.module.css
      - index.ts

</FileTree>

</Card>

<Card title="Smart placeholders" icon="pencil">
  One input automatically adapts to any naming convention in your file names, folder names, and content:

<Badge text="{name.raw}" variant="danger" size="medium" /> — Original input as typed

<Badge text="{name.camel}" variant="caution" size="medium" /> — camelCase (`myComponent`)

<Badge text="{name.pascal}" variant="success" size="medium" /> — PascalCase (`MyComponent`)

<Badge text="{name.kebab}" variant="note" size="medium" /> — kebab-case (`my-component`)

<Badge text="{name.snake}" variant="tip" size="medium" /> — snake_case (`my_component`)

</Card>

<Card title="Global and local" icon="setting">

Manage blueprints at two levels with automatic merging:

- **Global:** Saved directly in your VS Code `settings.json` for all projects.
- **Local:** Saved in `blueprintor.config.js` in the project root (**takes priority** if names collide).

</Card>

<Card title="Safe by default" icon="approve-check">

Everything is checked before writing, so a mistake in a config never leaves a half-created result. Existing files are never overwritten without asking.

</Card>

</CardGrid>
