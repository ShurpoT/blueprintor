<Aside title="Requirements">
  Visual Studio Code **1.103.0** or newer. A workspace folder must be open, as the extension operates within your project context.
</Aside>

## From the Marketplace

<Steps>

1. Open the Extensions view in VS Code: `Ctrl+Shift+X` (`Cmd+Shift+X` on macOS).

2. Search for **Blueprintor**.

3. Click **Install**.

</Steps>

## From the command line

If you prefer using your terminal, execute the installation command.

```bash
code --install-extension ShurpoT.blueprintor
```

<Aside type="caution">
  For the best results, run this command in your **system terminal** (like Terminal or PowerShell) rather than the integrated
  terminal inside VS Code, as the latter might sometimes spawn an empty window.
</Aside>

## Verify Installation

To check if the extension is active, open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`) and search for **Run Blueprintor...**.

You can trigger your blueprints from three different places:

- 🖱️ **Context Menu:** Right-click any folder in the Explorer.
- 📂 **Explorer Toolbar:** Click the Blueprintor icon at the top of the Explorer view.
- ⌨️ **Command Palette:** Search for the run command directly.

<Aside type="tip" title="Where will the files be created?">

The target folder for generation depends on how you launch the extension:

- **From the context menu:** Files are created inside the folder you right-clicked.
- **From the Explorer button or Command Palette:** Files are created inside the currently highlighted folder (or the parent folder of the active file). If no item is selected, the **workspace root** is used as a fallback.

</Aside>
