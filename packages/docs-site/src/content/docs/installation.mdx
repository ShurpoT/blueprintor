<Aside title="Requirements">

Visual Studio Code 1.103.0 or newer. A workspace folder must be open: the extension does nothing without one.

</Aside>

## From the Marketplace

<Steps>

1. Open the Extensions view: `Ctrl+Shift+X` (`Cmd+Shift+X` on macOS).

2. Search for **Blueprintor**.

3. Click **Install**.

</Steps>

## From the command line

```bash
code --install-extension ShurpoT.blueprintor
```

## From a VSIX file

1. Open the Extensions view.
2. Click `...` in the top right and choose **Install from VSIX...**.
3. Select the downloaded file.

## Verify

Open the Command Palette (`Ctrl+Shift+P`) and look for **Run Blueprintor...**. The command is also available:

- in the context menu of a folder in the Explorer;
- as a button in the Explorer view title.

The extension has no default keybinding.

<Aside type="tip" title="Which folder is the target?">

From the context menu, the target is the folder you right-clicked.

From the Explorer title button or the Command Palette, the target is the item currently selected in the Explorer (its parent folder, if it is a file). If that can't be determined, the workspace root is used.

</Aside>
